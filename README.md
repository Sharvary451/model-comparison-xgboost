# Model Optimization & Comparison (ECS7020P Project)

Compared performance of four classification models to determine best fit for tabular data.

## 🔧 Tools & Technologies
- Python, Scikit-learn, XGBoost, Pandas, Matplotlib

## 🧠 Approach
- Trained Logistic Regression, SVM, Random Forest, XGBoost
- Used GridSearchCV for hyperparameter tuning
- Evaluated using F1-score, confusion matrix, ROC curves

## 📈 Results
- XGBoost outperformed others with ~20% gain in F1
- Created a reusable workflow for model selection
